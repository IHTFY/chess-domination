# PWA icon concepts

Five original, editable 512 × 512 SVG concepts for Chess Domination. Open `index.html` for the comparison sheet, including circle and small-size previews. Click any large icon to open the source SVG.

1. **Sovereign** — classic gold queen on petrol.
2. **Blue Knight** — angular ivory knight on electric blue.
3. **Control Grid** — mint board, coral queen, and control rays.
4. **Citadel** — cream rook in a vermilion seal.
5. **Dominion** — checkerboard D on acid yellow with lavender accents.

Icons use native vector paths and shapes, with no fonts, scripts, external resources, or embedded raster images. Backgrounds fill the square; rounded and circular crops are applied only in the preview. These are options for review, not changes to the active PWA manifest. Once selected, export PNG fallbacks for installation platforms that need them and confirm platform mask crops.
